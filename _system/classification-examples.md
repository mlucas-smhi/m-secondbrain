# Classification Examples

## Purpose

This document provides examples of correct classification behavior.

When a classification decision is unclear, these examples should take precedence over assumptions.

The objective is consistency, predictability, and prevention of taxonomy drift.

---

# Positive Examples

## Idea

Input:

"We could use GitHub as Alfred's memory system."

Classification:

Type: Idea

Reason:

A possibility is being proposed.
No decision has been made.
