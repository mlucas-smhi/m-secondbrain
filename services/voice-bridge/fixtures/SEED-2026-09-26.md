## Reproducibility

From the repo root, preview both deterministic plans (synthetic data only):

```sh
PYTHONPATH=services/voice-bridge python3 -m bridge.memory_scenarios
PYTHONPATH=services/voice-bridge python3 -m unittest discover -s services/voice-bridge/tests -p 'test_memory*.py' -v
```

`memory_scenarios.build()` creates the provider-neutral plan.
`apply(plan, request)` requires a provisioned empty graph with exactly matching
`plan['metadata']`; the request adapter takes `(method, path, body=None)` and
returns parsed LiteGraph REST JSON. `verify(plan, request)` compares full records.
Reapplying a committed seed is deliberately a no-op, not a reset command.
After conversational mutations, strict baseline verification should fail; inspect
the mutation or use a separately versioned suite for a clean comparison. Never
delete or overwrite a working test graph to obtain a clean score implicitly.
