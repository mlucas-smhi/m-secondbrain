# Git as Canonical Brain

## Decision

GitHub repository will serve as the canonical knowledge store.

Obsidian will be treated as a user interface rather than the primary system of record.

## Reasoning

Advantages:

- Cloud accessible
- Human readable
- Version controlled
- Easily backed up
- Vendor independent
- Supports future platform changes

## Alternatives Considered

- Obsidian as primary storage
- Anytype
- Capacities
- Custom database

## Expected Benefits

- Reduced vendor lock-in
- Easier integration with Alfred
- Simplified retrieval architecture

## Associated Projects

- Alfred Memory System
- Obsidian POC
